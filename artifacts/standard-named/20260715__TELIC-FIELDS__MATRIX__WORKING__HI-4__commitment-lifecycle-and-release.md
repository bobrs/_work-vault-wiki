# Commitment Lifecycle and Release Matrix

Status: candidate pre-production  
Content canon status: unset

| State | Meaning | Permitted effect | Required next step |
|---|---|---|---|
| Proposed | Commitment has been expressed but not fully formed | Deliberation only | Confirm authority, scope, standing, and reliance |
| Active | Valid commitment governs within scope | Bounded recruitment of future action | Monitor review triggers and expiry |
| Conditional | Commitment governs only while stated conditions hold | Limited action | Reassess when condition changes |
| Due for review | A material trigger has occurred | Preserve history; narrow new action | Continue, renew, narrow, transfer, pause, repair, release, or dissolve |
| Contested | Authority, meaning, scope, or consequence is disputed | Reversible protection only where permitted | Competent review |
| Breached | Action departed from commitment or temporal rule | Stop expansion; preserve consequence | Repair, compensate, release, or dissolve |
| Partially fulfilled | Some obligation or reliance remains | Complete bounded remainder | Review residual obligation |
| Fulfilled | Commitment completed | Historical witness only | Release active authority |
| Released | Commitment no longer governs future action | Preserve valid reliance and consequence | Transition, repair, or close |
| Expired | Valid interval ended | No new authority | Renew explicitly or archive |
| Superseded | New version governs | Historical explanation only | Propagate current version |
| Dissolved | Governing loop ended | Residual state only | Assign custody, repair, and deletion |

## Review triggers

```text
material health change
caregiving change
authority change
scope mismatch
consent expiry
new affected center
irreversible consequence
reliance change
policy change
succession
breach
```

## Release test

A release process should identify:

- what future authority ends;
- what history remains;
- which reliance remains valid;
- which obligations survive;
- what notice or transition is needed;
- whether compensation or repair is required;
- whether dissolution is more legitimate than continuation.

## Governing principle

> A promise can remain honorable without remaining absolute.
