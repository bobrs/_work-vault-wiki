# Source Standing, Access, and Transition Authority Matrix

Status: candidate pre-production  
Content canon status: unset

| Question | Required distinction | Failure prevented |
|---|---|---|
| Can the source be reached? | Technical accessibility | Access-as-permission |
| May the source be copied? | Collection authority | Public-crawl overclaim |
| Did a center consent? | Consent scope and evidence | Silence or notice as consent |
| Is another authority basis present? | License, mandate, contract, stewardship, or other basis | Consent as the only possible authority |
| Who has standing? | Author, community, described people, custodian, public | Ownership-only analysis |
| May the source be transformed? | Transition-specific authority | One-grant-for-everything |
| May the source enter training? | Training purpose and recipient | Publication becoming training permission |
| May the model be released? | Release authority and restrictions | Training permission becoming release permission |
| May the model be deployed here? | Deployment purpose, affected centers, and authority | Deployment laundering |
| May outputs be reused for training? | Output-capture and retraining scope | Hidden recursive recruitment |
| Can authority expire or withdraw? | Effective time, withdrawal, residuals | Perpetual permission |
| Do restrictions reach successors? | Derivative propagation | Obligation loss |

## Transition chain

```text
create
→ publish
→ collect
→ store
→ aggregate
→ filter
→ transform
→ annotate
→ rank
→ train
→ evaluate
→ release
→ deploy
→ log
→ retrain
→ transfer
→ succeed
→ dissolve
```

Each arrow may require a different authority profile.

## Hard distinctions

```text
accessible ≠ permitted
permitted ≠ consented
consented ≠ owned
owned ≠ legitimate in every use
documented ≠ authorized
public ≠ ownerless
```

## Source-standing minimum

```text
source centers
affected centers
collective or community standing
creation context
publication context
custody
rights and interests
sensitivity
restrictions
contestation
review
```

## Governing principle

> A source can enter a technical pipeline without losing the standing, restrictions, and relationships that made the source meaningful.
