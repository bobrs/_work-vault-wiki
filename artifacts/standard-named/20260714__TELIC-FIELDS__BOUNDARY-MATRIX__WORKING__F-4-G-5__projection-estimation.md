# Projection Estimation — Boundary and Evidence Matrix

Status: draft  
Content canon status: unset

| Concept | Decision | Boundary |
|---|---|---|
| Telic projection estimation | Retain | Scoped, uncertain construction; never direct access to a true field |
| Telic projection | Retain | Source-attributed, lossy, corrigible representation |
| Receiver mirror | Retain | Receiver interpretation, not a copy of the source projection |
| Evidence class | Adopt | Direct, confirmed, delegated, observed, inferred, institutional, bodily, historical |
| Source authority | Retain | Privileged self-description, not infallibility |
| Interpretive authority | Retain | Permission to propose meaning, not permission to act |
| Action authority | Retain | Must be separately grounded in consent, delegation, role, or law |
| Uncertainty profile | Adopt | Multidimensional; confidence alone is insufficient |
| Projection expiration | Retain | Default lifecycle requirement for volatile projections |
| Projection revocation | Retain | Must disclose technical limits on downstream reversal |
| Projection integrity | Retain | Epistemic, semantic, authority, temporal, privacy, and correction integrity |
| Inferential privacy | Adopt | Protection against unauthorized sensitive inference |
| Direct statement | Strong evidence class | Scope-bound and potentially incomplete |
| Observed behavior | Evidence only | Does not transparently reveal preference |
| Model inference | Evidence only | Must remain marked and source-correctable |
| Calibration | Required where confidence is used | Does not create legitimacy or consent |
| Data availability | Not permission | Accessible information may remain outside authorized interpretation |
| Complete context | Reject as default | Minimum necessary projection governs |

## Governing distinctions

```text
field ≠ projection
projection ≠ receiver mirror
prediction ≠ preference
accuracy ≠ validity
confidence ≠ authority
availability ≠ permission
correction ≠ erasure
revocation ≠ guaranteed unlearning
```
