# Trace, Memory State, Retrieval, and Authority Matrix

Status: candidate pre-production  
Content canon status: unset

| Object or state | What it preserves | What it may do | What it may not do |
|---|---|---|---|
| Source event | Living occurrence and participant relation at the time | Generate witnessed traces | Become fully reproducible from the record |
| Durable trace | Selected persistent difference | Support later interpretation | Claim to contain the whole field |
| Active memory | Current action-relevant trace | Enter ordinary retrieval under authority | Override corrections, boundaries, or restrictions |
| Active with conditions | Current trace with explicit limits | Guide bounded action | Expand beyond conditions |
| Reference only | Reviewer-visible trace | Explain or compare | Enter automated action |
| Archive | Historical trace | Explain prior events and versions | Authorize current consequential action |
| Restricted memory | Trace under access limits | Enter scoped retrieval | Become generally searchable |
| Quarantined memory | Potentially contaminated trace | Support investigation | Guide ordinary action |
| Stale memory | Once-useful trace no longer current | Explain historical action | Act as current source or authority |
| Released memory | Trace no longer governing the released purpose | Preserve bounded witness | Reactivate without new authority |
| Deleted memory | Content removed within known scope | Preserve narrow deletion witness where authorized | Remain retrievable through undeclared copies |
| Retrieval grant | Scoped permission to search or read | Permit named operation and recipient | Create action, disclosure, or training authority automatically |
| Action authority | Permission to affect the field | Use eligible traces for a named action | Convert relevance into legitimacy |

## Hard distinctions

```text
event ≠ trace
trace ≠ field
memory ≠ possession
retrieval ≠ authority
relevance ≠ permission
salience ≠ legitimacy
archive ≠ active governance
release ≠ historical erasure
```
