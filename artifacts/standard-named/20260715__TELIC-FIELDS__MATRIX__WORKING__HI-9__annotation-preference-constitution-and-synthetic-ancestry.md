# Annotation, Preference, Constitution, and Synthetic Ancestry Matrix

Status: candidate pre-production  
Content canon status: unset

| Layer | Must preserve | Must not become |
|---|---|---|
| Annotation | Contributor, role, instructions, conditions, compensation, authority | Invisible free semantic labor |
| Demonstration | Task, source, intended behavior, downstream scope | Universal example of human desire |
| Ranking | Candidate set, preference context, disagreement | Humanity's preference |
| Critique | Reviewer basis, evidence, scope | Absolute truth |
| Reward model | Preference source, aggregation, objective, biases | Public legitimacy engine |
| DPO or RLHF record | Dataset, method, disagreement treatment, provider role | Consent generator |
| AI feedback | Generating model, constitution, source dependence | Human judgment |
| Constitution | Authors, authority, adoption, conflicts, revisions | Legitimate merely because explicit |
| Synthetic data | Generating model, prompts, ancestors, restrictions, depth | Source-free material |
| Distillation | Teacher lineage, target purpose, restrictions | New model without ancestry |
| Evaluation | Evaluator, benchmark purpose, limitations | General legitimacy proof |

## Preference record minimum

```text
task
contributors
instructions
working conditions
compensation
source inputs
output type
preference context
disagreement
quality control
authority
consent
downstream use
withdrawal
```

## Constitution record minimum

```text
principles
principle sources
authors or authorities
affected centers
adoption process
training or inference use
conflicts
exceptions
revision history
contest route
```

## Synthetic ancestry minimum

```text
generating models
generation process
ancestor sources
ancestor authority
ancestor restrictions
transformations
filtering
contamination risks
recursive depth
withdrawal links
```

## Governing principles

> Preference data is a projection of judgment under a task, not a sample from a single human telos.

> Synthetic does not mean unowned, unbiased, source-free, or consent-free.
