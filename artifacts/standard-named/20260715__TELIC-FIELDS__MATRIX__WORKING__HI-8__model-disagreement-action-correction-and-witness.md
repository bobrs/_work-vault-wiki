# Model Disagreement, Action Boundary, Correction, and Witness Matrix

Status: candidate pre-production  
Content canon status: unset

| Condition | Meaning | Required response |
|---|---|---|
| Models agree | Outputs converge under observed inputs and methods | Treat as model evidence only; do not create authority |
| Models disagree | Method, prompt, source, calibration, or provider dependence may matter | Return to source, assumptions, participants, or authority |
| Sycophancy detected | Output aligned socially rather than faithfully | Quarantine output and compare against source trails |
| Participant correction | Represented source changes or contests model output | Update map, summary, recommendation, and witness |
| Participant refusal | Operation or use is denied within scope | Stop or narrow that operation |
| Provider refusal | Provider policy blocks operation | Attribute refusal to provider field |
| Recommendation ready | Candidate route appears plausible | Evaluate action gate |
| Tool permission present | Tool can technically execute | Still require scope, consent, authority, and context |
| Action authority missing | No competent center may authorize | Deny execution |
| Consent missing | Affected operation lacks valid permission | Deny or seek consent |
| Protected condition uncertain | Material boundary may be breached | Pause or require human re-entry |
| Human confirmation present | Human approves visible proposal | Does not cure hidden standing or context failure |
| Action completed | Tool returned a result | Record tool result separately from interpretation |

## Action-gate minimum

```text
tool permission
scope validity
consent validity
authority validity
context adequacy
protected-condition pass
reversibility review
human re-entry where required
```

## Correction propagation

```text
participant correction
→ active field map
→ standing-preserving summary
→ generated options and route comparison
→ tool plan
→ model-mediated decision witness
```

## Model-mediated witness minimum

```text
model roles
output classes
field maps
summaries
minority retention
provider disclosures
sycophancy events
model disagreement
tool boundaries
corrections and refusals
selected routes
actions and consequences
standing effect: none
authority effect: none
```

## Governing principle

> The model may prepare the transition from language to action. It may not erase the constitutional gate between them.
