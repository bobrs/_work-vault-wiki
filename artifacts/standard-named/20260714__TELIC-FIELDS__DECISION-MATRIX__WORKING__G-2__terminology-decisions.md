# G.2 Terminology Decision Matrix

Status: draft  
Content canon status: unset

| Term | Decision | Required boundary |
|---|---|---|
| Telic field | Retain | Distinguish from telic states, telic controllability, telic system, telic/paratelic states, linguistic telicity, and teleological centers of life |
| Local telic field | Retain | Indexed to a center; not a universal field |
| Relational telic field | Retain | Cite participatory sense-making; prove added value beyond interaction dynamics |
| Internal telic field | Retain cautiously | Non-clinical; do not reify parts |
| Simplified telic field calculation | Preserve in lineage | Replace in technical writing |
| Telic projection estimation | Adopt | Scoped, uncertain, corrigible inference |
| Telic projection | Retain | Projection is not field; receiver mirror is not projection |
| Telic projection integrity | Retain | Compare with model fidelity, requirements traceability, and semantic integrity |
| Polytely | Established neighbor | Multiple simultaneous goals |
| Polytelometry | Retain provisionally | Practice of making goal relations, authority, provenance, and consequences legible |
| Polytelometric navigation | Retain | Pre-optimization and governance layer |
| Semantic polytelometry | Retain | Candidate capability class, not goal extraction alone |
| Constitutional self | Retain | Governance-oriented synthesis; internal multiplicity is established prior art |
| Constitutional element | Retain internally | Avoid public clinical reification |
| Context carrying capacity | Retain | Not storage, working memory, token count, or requisite variety alone |
| Temporal standing | Retain | Candidate normative umbrella; distinguish legal, psychological, and metaphysical uses |
| Teleological integrity | Preserve in lineage | Broad and potentially misleading |
| Telic integrity | Prefer | Legitimate end-relative orientation surviving transformation |
| Teleological graft rejection | Preserve as evocative metaphor | Prefer telic incompatibility or constitutional substrate mismatch in technical work |
