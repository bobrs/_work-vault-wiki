# Dissent, Abstention, Delay, and Consequence Return Matrix

Status: candidate pre-production  
Content canon status: unset

| Public state | What must remain visible | What must not be inferred | Review route |
|---|---|---|---|
| Support | Position, reason, scope, conditions | Consent beyond scope | Consequence review |
| Opposition | Position, reason, evidence, prediction | Bad faith or disloyalty | Dissent trail and later comparison |
| Abstention | Reason, conflict, burden, missing context | Agreement | Method, access, or standing review |
| Refusal | Boundary, authority, affected operation | Rejection of every relation | Scope correction or fork |
| Deadlock | Methods, unresolved claims, cost bearers | Costless stasis | Change method, portfolio, trial, or escalate |
| Pause | Delay bearers, temporary protection, expiry | No consequence | Triggered return |
| No-decision | Governing status quo and its beneficiaries | Neutrality | Public delay witness |
| Minority dissent | Standing, reasons, predicted effects | Automatic veto | Protected-condition or consequence review |
| Implementation variance | Difference from selected route | Mere administrative detail | Authority and scope review |
| Unexpected consequence | Affected centers and changed cost map | Isolated anomaly by default | Reopen navigation |
| Confirmed dissent prediction | Which claim was supported | Complete vindication of every dissent claim | Targeted revision |
| Reversal or release | Why authority ended and obligations remain | Historical erasure | Repair and final witness |

## Delay witness

A pause or no-decision should record:

```text
reason
authority
status quo
cost bearers
delay bearers
temporary protection
information sought
review trigger
expiry
```

## Dissent trail

```text
centers
position
reasons
evidence
protected-condition claim
predicted consequence
requested review
future trigger
publication and privacy
```

## Consequence return

```text
observed consequence
predicted consequence
unexpected consequence
affected centers
cost-bearer change
protected-condition status
dissent comparison
revision options
authority
```

## Governing principle

> Public answerability begins where the selected action remains connected to the reasons, refusals, delays, and consequences it did not absorb.
