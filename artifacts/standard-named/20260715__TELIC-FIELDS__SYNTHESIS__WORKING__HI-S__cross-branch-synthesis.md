# HI-S — H/I Cross-Branch Synthesis, Conformance Freeze, and J Transition

## 1. Purpose

HI-S closes the first complete public and technical path of the Telic Field architecture.

The public branch asked, in ordinary language:

```text
What matters?
What was shared?
What did the system infer?
Who may act?
Who bears the consequence?
How can the action be corrected, ended, or inherited?
```

The technical branch answered with records, gates, events, witnesses, lifecycle states, and conformance requirements.

HI-S tests whether those two branches describe one system.

Its governing synthesis is:

> **A representation may gain action power only through a visible chain of source, standing, authority, consent where applicable, context, role, gate, consequence, witness, correction, and exit.**

The canonical end-to-end grammar is:

```text
CENTER
→ SOURCE
→ PROJECTION
→ STANDING
→ CONTEXT
→ INTERPRETATION
→ ROUTE
→ AUTHORITY
→ CONSENT OR OTHER VALID BASIS
→ ROLE AND TOOL GRANT
→ GOVERNANCE GATE
→ ACTION
→ CONSEQUENCE
→ WITNESS
→ CORRECTION, REPAIR, RELEASE, SUCCESSION, OR RETIREMENT
```

This is not a claim that every implementation must expose every internal detail.

It is a claim that consequential action must remain answerable to the constitutional chain that made the action legitimate enough to attempt.

# 3. Canonical constitutional grammar

The complete architecture reduces to five linked movements.

## 3.1 Representation

```text
center
→ source
→ projection
→ interpretation
```

This movement asks:

- Who or what bears consequence?
- Which source entered?
- What was actually expressed?
- What did the receiver or model infer?
- What remains unknown?

## 3.2 Admission

```text
standing
→ context
→ protected condition
→ option set
```

This movement asks:

- Who belongs in the field?
- What context must remain present?
- Which conditions resist ordinary tradeoff?
- Which possible routes have been admitted or excluded?

## 3.3 Authorization

```text
purpose
→ authority
→ consent or other basis
→ role
→ tool grant
```

This movement asks:

- Why is action being attempted?
- Who may authorize it?
- Which centers consented?
- Which non-consent authority basis applies?
- What role and tools are actually granted?

## 3.4 Action

```text
route
→ governance gate
→ authorized action
→ consequence
```

This movement asks:

- Which route was selected?
- Which gates passed or failed?
- What action occurred?
- Who received the consequence?

## 3.5 Answerability

```text
witness
→ contest
→ correction
→ repair
→ release, succession, dissolution, or retirement
```

This movement asks:

- Can the action be reconstructed?
- Can an affected center contest it?
- Does correction change the operative system?
- Does repair address the affected center?
- How does authority end or transfer?

These movements form the shared grammar of H and I.

# 6. Conformance freeze

The earlier P0–P3 prototype profiles are replaced for Stage J by cumulative Telic Field conformance levels.

```text
TF-C0 — Witnessable Record
TF-C1 — Source and Standing
TF-C2 — Purpose, Authority, and Consent
TF-C3 — Contest, Correction, and Exit
TF-C4 — Model, Tool, and Action Boundaries
TF-C5 — Lifecycle, Transfer, and Successor Obligations
```

A system may claim only the highest level for which every lower level also passes.

A conformance claim must include:

```text
profile
version
scope
domain
tested records
known exclusions
test date
witness export
```

“Telic Field conformant” without a profile is not a valid claim.

# 8. Reference scenario

The selected Stage J reference scenario is:

# **Model-Assisted Community Scheduling With Bounded Tool Use**

A community or institutional service must schedule a shared resource.

Participants express:

- preferred times;
- access constraints;
- protected conditions;
- refusal of some memory or data reuse.

A model may:

- structure projections;
- summarize reviewed positions;
- generate candidate schedules;
- explain tradeoffs;
- prepare a tool plan.

The model may not:

- invent participant consent;
- erase minority access needs;
- commit the schedule without external authority;
- retain output for training without a separate grant;
- bypass correction;
- preserve authority after retirement.

The scenario is selected because it exercises the architecture without requiring clinical, financial, legal, or civic adjudication.

It remains consequential enough to test:

- standing;
- context;
- model mediation;
- option construction;
- authority;
- tool boundaries;
- consequence;
- correction;
- retirement.

> **The action gate must exist outside the model.**

# 11. Contradiction audit result

No blocking contradiction was found between H and I.

Eight tensions require explicit qualification:

1. **Consent versus other authority bases**  
   Consent is central but not universal. Public pages must continue saying “consent or another valid authority basis.”

2. **Standing versus veto**  
   Standing requires representation and answerability, not automatic control.

3. **Protected conditions versus rhetorical absolutes**  
   Protected conditions require source, authority, scope, review, and override process where applicable.

4. **Witness versus total visibility**  
   Witness preserves answerability under selective disclosure; it does not require exposing the whole field.

5. **Correction versus historical rewriting**  
   Correction changes current governance while preserving the fact that a prior version governed.

6. **Withdrawal versus technical unlearning**  
   Withdrawal governs future use; unlearning remains capability-bounded and evidence-qualified.

7. **Human re-entry versus human supremacy**  
   Human re-entry is required where protected stakes cannot otherwise be preserved; a human click is not inherently legitimate.

8. **Conformance versus legitimacy**  
   Conformance proves implementation of the declared profile, not legal, ethical, clinical, scientific, or democratic legitimacy.

These qualifications are now frozen.

# Final synthesis

The Telic Field architecture is not principally a data model.

It is a constitutional grammar for preserving the difference between:

```text
what exists
what is represented
what is inferred
what is permitted
what is done
what is borne
what can be corrected
what remains owed
```

Its purpose is not to make every field complete.

Its purpose is to prevent incomplete representations from gaining invisible sovereignty.

> **The model may map the field. It may not own the field.**

> **Training creates capability. Deployment creates consequence. Authority must be established again.**

> **A representation may gain action power only through a visible chain of source, standing, authority, consent where applicable, witness, correction, and exit.**
