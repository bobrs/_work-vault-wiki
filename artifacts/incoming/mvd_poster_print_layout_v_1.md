## Design Notes (for print — full spec)

### Page
- Size: US Letter (8.5 x 11 in) portrait  
  (A4 compatible: maintain margins + scale ~97%)
- Margins: 0.75 in all sides
- Grid: single column, vertical rhythm 12pt baseline

### Typography
- Primary font: Inter (fallback: Helvetica / Arial)
- Title:
  - Size: 36–42 pt
  - Weight: 700 (bold)
  - Tracking: +1%
  - Alignment: center
- Subtitle ("If lost → start here" + "☐ Start anywhere"):
  - Size: 14–16 pt
  - Weight: 500
  - Color: 70% gray
  - Alignment: center
  - Style: slightly lighter to reduce pressure
- Section Headers (e.g., “1. 🪞 Mirror (morning)”):
  - Size: 18–20 pt
  - Weight: 600
  - Color: near-black (#111111)
- Core Statement (e.g., “You are loved.”):
  - Size: 16–18 pt
  - Weight: 600
  - Color: #111111
- Instruction Line (italic micro-steps):
  - Size: 11–12 pt
  - Weight: 400
  - Style: italic
  - Color: 55% gray
- Invariants + Footer:
  - Size: 11–12 pt
  - Weight: 500
  - Color: 60% gray

### Spacing
- Section block spacing: 18–24 pt above, 12–16 pt below
- Line spacing:
  - Headers: 1.2
  - Body: 1.35–1.45
- Add extra space before each checkbox for visual pause

### Color & Material
- Background: off-white / warm cream (#FAF7F2)
- Text: near-black (#111111)
- Secondary text: gray (#6B6B6B)
- Icons (emoji): monochrome feel (avoid bright color distraction)
- Paper: matte finish preferred (reduces glare, increases calm field)

### Checkbox System (critical)
- Size: 0.28–0.35 in square
- Stroke: 1.5–2 pt
- Corner radius: 2–3 px (slight softness)
- Spacing: 8–12 pt from instruction line
- Use laminated surface for dry-erase reuse

### Visual Hierarchy (distance behavior)
- From 6–10 ft:
  - Only headers readable (Mirror, Breathe, Nourish…)
- From 2–4 ft:
  - Core statements readable (You are loved, Feel your body…)
- From 1 ft:
  - Instructions + checkboxes usable

### Layout Principles
- High whitespace density (avoid clutter)
- No borders or heavy lines
- Vertical flow uninterrupted
- Each section visually self-contained

### Optional Enhancements (light touch)
- Alternate very subtle background bands per section (2–3% tint)
- Bold the first verb in each instruction line (e.g., *look*, *reach*, *drink*)
- Add faint footer micro-line:
  - "One is enough."
