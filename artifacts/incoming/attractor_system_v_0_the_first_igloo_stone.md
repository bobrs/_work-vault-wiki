### 1. Canon
The current best compressed answer.

### 2. Dissent Shelf
Runner-up variants that almost became canon.

### 3. Parents (Reverse Git)
The attractors whose compression produced this one.

### 4. Promotion
Any dissent can become a new attractor.

That’s it.

No artifacts-as-truth.
No endless notes.

## 🜹 Replay / History (Selective Excavation)

History is always permanent.

But interpretation is optional.

The client may choose to reinterpret deeper lineage *only when useful*:

- shallow view = fast, stable attractor canon
- deeper excavation = more nuance, more dissent recovery

This comes at a cost:

- additional local inference
- more context assembly
- slower rendering

So replay is not default clutter.

It is an intentional depth dial:

> “Cast my web wider, interpret more history.”

No endless logs.
Only selective excavation when requested.
