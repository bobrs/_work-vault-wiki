# 🜛 Minimum Viable Day (MVD) — v0.1
**Attractor-Preserving, Resource-Minimal Runtime**

---

## 🧭 Core Invariants (Do Not Break These)

Every day must contain:

1. Self before signal  
2. Body included  
3. One value loop closed  
4. One real human touch  
5. One moment of beauty / gratitude  
6. No coercion by urgency  

If a day has these → it is a successful day.

# 🌅 Phase 1 — Wake (Self-State Initialization)

**Goal:** establish sovereignty before input

Minimal:
- Wake without phone
- 3–10 slow breaths
- Feel body (no fixing)

Optional:
- Step outside or to window
- Light movement / stretch

Anchor:
> Nothing has authority yet.

---

# 🍵 Phase 2 — Nourishment (Signal Calibration)

**Goal:** break reactive consumption

Minimal:
- Water or tea
- Eat with attention

Constraint:
- No scrolling while eating

Anchor:
> This is enough, and I notice it.

---

# ⚙️ Phase 3 — Value Loop (The Engine)

**Goal:** close one real loop

Loop definition:
> problem → help → value acknowledged (ideally paid)

Constraints:
- Finishable in 1–3 hours
- Produces clear value

Anchor:
> One loop closed = day is real.

---

# 🜁 Phase 4 — Sovereignty Injection (Midday Reset)

**Goal:** prevent drift

Minimal:
- Pause 2–5 minutes
- Feel body

Optional:
- Walk or stretch

Anchor:
> Signal is data, not command.

---

# 🤝 Phase 5 — Relational Touch (Field Seeding)

**Goal:** build trust-dense field

Minimal:
- One sincere, non-extractive interaction

Examples:
- Appreciation
- Specific help
- Invitation

Anchor:
> I see you.

---

# 🔥 Phase 6 — Environment + Creation

**Goal:** express agency in space

Minimal:
- Clean one surface
- Prepare simple food
- Adjust light
- Step outside

Anchor:
> I shape my environment.

---

# 🌙 Phase 7 — Closure (Loop Completion)

**Goal:** prevent psychic leakage

Minimal:
- Name one thing done
- Name one value given

Optional:
- Write 1–3 lines

Anchor:
> The loop is closed.

---
