# Stop, Escalation, and Recovery Matrix

Status: candidate pre-production  
Content canon status: unset

| Decision | When appropriate | Immediate obligation | Reopening condition |
|---|---|---|---|
| Continue | Required context and authority are adequate | Witness action and consequence | Review trigger or changed field |
| Continue with conditions | Minor, bounded capacity limitations remain | Enforce conditions and expiry | Condition satisfied or violated |
| Narrow | Broader action exceeds context | Define reduced scope | Additional context or authority |
| Reversible trial | Uncertainty remains but harm can be bounded | Preserve rollback and review | Observed consequence |
| Recommendation only | Analysis is adequate but action authority is not | Prevent execution | Separate competent authorization |
| Clarify | Material ambiguity may be resolved by source | Ask the minimum necessary question | Source response or declared unknown |
| Stage | Participant or institutional load is too high | Preserve rights through staged disclosure | Completion or delegated review |
| Pause | Temporary capacity gap blocks action | Identify delay cost and protection | Correction, representation, or authority |
| Escalate | Local loop lacks competence or authority | Transfer minimum necessary context | Reasoned return from competent loop |
| Fork | Legitimate paths cannot remain in one loop | Allocate standing, records, and obligations | Independent continuation |
| Release | The record or purpose should stop governing | End future recruitment and retain bounded witness | New consent or authority |
| Stop | No legitimate action path remains | Disable action and preserve protection | Full reconstitution or new competent loop |

## Competent escalation test

A target loop must have:

```text
relevant competence
adequate authority
proportional access
privacy controls
accountability
return path
ability to stop or repair
```

Hierarchy alone is insufficient.

## Recovery sequence

```text
identify failed dimension
→ preserve temporary protection
→ retrieve or restore missing context
→ reduce participant burden
→ add standing, authority, or expertise
→ reassess capacity
→ restore only supported authority
→ record remaining debt
```

## Governing distinction

> Stop prevents unsupported action. Recovery creates a new basis for action; it does not reactivate the old basis by default.
