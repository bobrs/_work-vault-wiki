# Minimum Context by Action Class

Status: candidate pre-production  
Content canon status: unset

| Action class | Minimum context | Typical maximum authority | Required safeguards |
|---|---|---|---|
| Ephemeral assistance | Current request, model role, source/generated distinction | Respond or structure | Easy correction; no durable action |
| Reversible draft | Request, recipient, purpose, scope | Draft only | Human review before sending |
| Recommendation | Material sources, uncertainty, alternatives, authority limits | Recommend | No automatic execution |
| Bounded trial | Standing, protected conditions, reversibility, review | Execute within trial scope | Rollback and consequence review |
| Consequential decision | Current evidence, corrections, standing, authority, privacy, appeal | Authorize or execute under role | Decision witness and recourse |
| Irreversible action | Full action-specific demand profile, strong standing coverage, current authority, consequence analysis | Domain-specific competent authority | Independent review and stop control |
| Emergency protective action | Immediate threat, bounded emergency authority, minimum necessary action | Temporary protective action | Expiry, witness, after-action review |

## Proportionality rule

The system should collect the context required for the action it may take.

It should not collect the context required for a more powerful action merely because that information may be useful later.
