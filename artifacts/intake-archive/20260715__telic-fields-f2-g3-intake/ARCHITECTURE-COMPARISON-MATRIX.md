## Interpretation

The matrix does not rank entire disciplines.

It identifies which components semantic polytelometry should reuse and where the proposed architecture still needs empirical justification.

## Minimum claimed additions

Semantic polytelometry is distinct only if it demonstrably preserves:

1. centers of standing;
2. field/projection/mirror separation;
3. statement/inference separation;
4. consent to telic recruitment;
5. unresolved remainder;
6. relation-level teloi;
7. context capacity and stopping;
8. source correction;
9. provenance across transformations;
10. model non-sovereignty;
11. operational exit and revocation.
