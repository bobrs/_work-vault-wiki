# Model Memory and Cross-Loop Transfer Matrix

Status: candidate pre-production  
Content canon status: unset

| Transition | Required distinction | Required authority | Principal risk |
|---|---|---|---|
| Current conversation → session memory | User statement, tool result, model inference, model generation | Current-session operation | Inference laundering |
| Session memory → cross-session memory | Temporary context versus approved durable preference | Explicit retention basis | Relationship inflation |
| Cross-session → cross-user use | Personal memory versus aggregate use | Separate cross-user authority | Hidden recruitment |
| Saved memory → training | Retrieval use versus model improvement | Separate training authority | Consent scope expansion |
| Source loop → target loop | Source artifact versus transformed summary | Transfer purpose and recipient | Transformation concealment |
| Private channel → shared channel | Private source versus approved projection | Source-controlled disclosure | Context leakage |
| Active memory → archive | Current authority versus historical relevance | Archival policy | Stale authority reuse |
| Archive → reactivation | Historical record versus current source | Renewed validity and authority | Persistence as legitimacy |
| Release → deletion | End of governance versus content removal | Release and deletion authority | Deletion theater |
| Model output → institutional record | Candidate inference versus official classification | Competent institutional authority | Model inference becoming state fact |

## Model-session envelope minimum

```text
memory sources

```

## Governing principle

> Machine readability makes a trail actionable. It does not make the trail sovereign.
