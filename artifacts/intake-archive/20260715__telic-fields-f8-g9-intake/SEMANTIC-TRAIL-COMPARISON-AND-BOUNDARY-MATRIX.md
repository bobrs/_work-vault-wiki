## Governing distinctions

```text
terrain ≠ trail
trace ≠ meaning
persistence ≠ integrity
information ≠ truth
truth ≠ legitimacy
graph edge ≠ source field
machine readability ≠ authority
shared access ≠ commons governance
provenance ≠ consent
correction ≠ erasure
reactivation ≠ continuing validity
```

## Terminology warning

`Semantic field` already has established meanings.

Every Telic Field use must include the scoped definition:

> The distributed, revisable ecology of traces, conventions, artifacts, relations, and interpretive practices through which prior distinctions become available to current and future navigation.

A narrower technical alternative is:

```text
semantic-trail ecology
```
