# Canon Map

Status: working orientation  
Source role: corpus orientation

This file identifies current source-of-record rules for working with the Work Vault Wiki. It is not a complete theory map.

## Operational Canon

- Witness before mutation.
- Retrieve before reasoning.
- Cite before extending.
- Markdown wiki pages are the preferred semantic layer.
- Raw artifacts are witness/reference material.
- Standard-named source copies are preferred over inbound originals when available.
- Attractor pages are navigation gateways unless explicitly marked canonical.
- Concept pages are stabilized semantic surfaces unless explicitly marked otherwise.
- Published external feeds are publication metadata, not raw intake.
- AI memory is not sufficient source authority when repository or wiki sources are available.
