# Status Vocabulary

Status: current guidance  
Source role: corpus operating vocabulary  
Layer: semantic wiki interface

This page defines operational status and source-role terms used in the Work Vault Wiki.

## Status Terms

### Canonical
Approved or explicitly current source-of-record material.

### Current guidance
Operational guidance that should be followed unless superseded.

### Candidate
Material proposed for possible reuse but not yet approved.

### Draft
Work in progress.

### Archive
Retained for history or provenance.

### Deprecated
Material that should not be treated as current except when discussing history or lineage.

### Generated index
A page produced from scripts, manifests, inventories, or other repo data.

### Review queue
Material awaiting classification, duplicate review, conversion, or human adjudication.

## Source Role Terms

### Semantic wiki layer
Markdown/wiki pages used for navigation, compression, and interpretation.

### Raw artifact
Original or source-like file preserved as evidence or witness.

### Witness/reference material
Material that should be preserved and cited but not necessarily treated as current semantic canon.

### Inbound original
A provenance-bearing intake file.

### Standard-named source copy
A normalized or repo-standard source file preferred for citation when available.

### Published external metadata
Metadata imported from an external published surface.

## Rule

When status is unclear, say so. Do not silently promote material to canon.
