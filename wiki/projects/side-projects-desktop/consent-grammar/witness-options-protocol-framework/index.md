## Working Read

Witness is treated here as the primary non-transformative primitive. Options come after witness, not inside it, so observation does not quietly smuggle in evaluation, logging, or intervention.

## Core Claim

If witness is to remain trustworthy, downstream operations must be explicit branches. Presence, witness, option, and release are different states, and the protocol keeps them from collapsing into each other.

## Key Ideas

- Witness is disciplined non-interference.
- Options are downstream branches.
- Consent belongs between offer and execution.
- Release must return agency cleanly.
