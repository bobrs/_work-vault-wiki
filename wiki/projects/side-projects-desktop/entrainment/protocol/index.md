## Working Read

The protocol is a self-governance artifact. It starts from a single file, carries human-readable intention alongside machine-readable structure, and preserves the continuity spine across planning and execution cycles.

Its significance is practical rather than mystical: if the same file can keep the user, the AI, the action set, and the review history in one place, the system can remain bounded, reversible, and legible over time.
