# Spec

This seam holds the ACT–POLICY substrate specification.

It defines the four core primitives of the system: ACT, POLICY, WITNESS, and STATE. The important move is not the exact syntax; it is the decision to make consent, verification, and semantic change explicit enough that they can be evaluated and logged.

## Working Read

The spec is a minimal substrate for consent-bound meaning systems. It intentionally excludes UX, legal procedure, trust scoring, and metaphysical identity assumptions so those can remain layered views rather than accidental primitives.

That makes it a clean sibling to the existing consent and witnessing vocabulary. It is especially close to Governance Diad, Witnessing, and Consent Physics because all three already treat legitimacy, certification, and state change as structurally separable concerns.
