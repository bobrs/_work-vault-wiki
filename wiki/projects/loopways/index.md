# Loopways

This project collects the interloop exchange layer: the paths through which witnessed consent loops move value, state, obligation, recourse, memory, and authority without collapsing into one owner or one platform.

It is the project home for the loopways specification and the surrounding exchange vocabulary. The page stays close to LoopLink, WitnessKey, LOOPtLOOP, and the consent/custody branch of the corpus.

## Working Read

Loopways is not a single currency or one universal platform. It is a consented path between loops, where each loop can define what it recognizes, what it emits, what it accepts, and what recourse exists if exchange fails.

The core claim is that witnessed loops can nest, translate, and route into larger loops without losing their own standing. That makes the project relevant anywhere the corpus wants portability, recourse, surplus routing, or boundary-preserving exchange.
