# AI Answer Contracts

Status: current guidance  
Source role: AI grounding surface  
Layer: semantic wiki interface

This page defines preferred answer shapes for AI tools working from the Work Vault Wiki.

## Corpus-grounded answer

Use this when answering questions about the wiki, projects, concepts, attractors, essays, or source inventory.

1. Sources consulted
2. Corpus-grounded claims
3. Inferences beyond the corpus
4. Conflicts, stale areas, or missing sources
5. Suggested corpus updates

## Mutation answer

Use this when changing repository or wiki files.

1. Files inspected
2. Files changed
3. Source or witness material preserved
4. Navigation or indexes updated
5. Build or validation results
6. Follow-up risks or recommended next steps

## Synthesis answer

Use this when creating new conceptual material from the corpus.

1. Source materials used
2. Existing canon or stable concepts
3. New synthesis
4. Candidate additions
5. Questions requiring human adjudication

## Conflict answer

Use this when sources disagree.

1. Conflicting sources
2. Nature of conflict
3. Most current or authoritative source, if determinable
4. Unresolved ambiguity
5. Recommended adjudication
